販売する前に、すべての素材について「商用で使ってよいか」「表記が必要か」を確かめてください。
**未確認** のものは、確認がすむまで販売版に入れないでください。

## 画像生成 AI について

- Steam で売る場合、AI で作った素材を使っていることを申告する必要があります（ストアの申請フォームにあります）。
- 使ったサービスによっては、商用利用に有料プランが必要だったり、出力の扱いに条件があったりします。生成したときのアカウントのプランと規約を確認してください。
- 背景の元画像のうち `bg_*.png` には右下に透かし（Gemini のマーク）が入っていました。ゲームでは 16:9 に切り抜く都合でその部分は画面に入りません。AI 生成であることはクレジットと販売ページに明記してください。

## 素材を作りなおすとき

`tools/prepare_assets.py` が元の WinForms 版の `Resources` フォルダーから、透過・切り抜き・縮小・Ogg 化までを行います。

```bash
python3 tools/prepare_assets.py <元の Abbild フォルダー> --fonts <DotGothic16 のフォルダー>
```
