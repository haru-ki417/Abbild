## BGM について（OpenTracks の音源利用ライセンス）

確認日：2026-10-03。ライセンス本文：https://opentracks.com/help/articles/license/ ・利用規約：https://opentracks.com/help/articles/terms/

- **商用・有料のゲームで使ってよい**（「営利（商用）・非営利」を問わない。アプリ・ゲームの背景音楽としての利用は認められている）。
- **クレジット表記は不要**（「著作権表示・提供等の表示は不要です」）。お礼としてクレジットには書いておく。
- **禁止されていること**（このゲームに関係するもの）
  - 遊ぶ人が「音源ファイルに音声ファイルとしてアクセス、複製が可能な状態」で使うこと
    → 対応済み：Ogg をそのまま置かず、`tools/pack_bgm.py` で名前ごとの鍵でかき混ぜて `Content/bgm.dat` 1 つにまとめた。ゲームはメモリ上で戻して流す。配布物にも Git にも Ogg は入れない（元の Ogg は `assets-src/bgm/`、.gitignore 済み）。
  - 音源そのものの配布・販売（サウンドトラックとして売る、BGM だけを配る など）。
  - YouTube の Content ID などのフィンガープリントに登録すること（プレイ動画を出すときも登録しない）。
  - AI の学習に使うこと。
- **作曲者ごとの条件が優先される**（「作曲・制作者の利用条件が優先され…」）。わかっている 2 曲は確認ずみ：
  | 使っているところ | 曲名 | 作曲者 | 作曲者の条件 |

  | タイトル | BitCastle（https://opentracks.com/bgm/detail/3645） | こおろぎ | サイトのライセンスに準拠。ニコニコ動画で使う場合は親作品登録（nc119944）のお願いあり。使ってよいかの個別の問い合わせには返信しない方針 |

- **公開リポジトリ（GitHub）には BGM を入れない。** `bgm.dat` は .gitignore 済みで、手元（`tools/pack_bgm.py` で作る）と販売用の配布物にだけ入れる。公開前に、これまでの履歴からも Ogg と `bgm.dat` を取り除いた（git filter-repo）。かき混ぜ方のコードは公開されているので、`bgm.dat` を公開の場所に置くと「かんたんに取り出せる状態」になってしまう点に注意。

## Gemini の画像について

確認日：2026-10-03。Google 利用規約：https://policies.google.com/terms ・生成 AI の追加規約：https://policies.google.com/terms/generative-ai ・使用禁止ポリシー：https://policies.google.com/terms/generative-ai/use-policy

- Google 利用規約は、サービスで生成したオリジナルのコンテンツについて「Google がそのコンテンツに対する所有権を主張することはありません」としている。生成した画像をゲームに入れて売ることを禁じる条項は見当たらない。
- 守ること
  - **出どころを偽らない**：使用禁止ポリシーは「人々を欺くことを目的に、人間によってのみ作成されたコンテンツであると主張し、生成されたコンテンツの出所を偽る」ことを禁止している。クレジット・販売ページに「AI（Google Gemini）で生成」と書く（クレジットは記載済み）。「すべて手描き」などと宣伝しない。
  - **他人の権利を侵害しない**：既存のキャラクター・作品に似た絵がないか、販売前に全体を見直す（似ていたら差しかえる）。
  - AI の学習に使わない（規約で禁止）。
- 知っておくこと
  - AI だけで作った画像は、日本でも海外でも著作権で守られないことがある（人の創作的な関与が少ないため）。他の人に絵だけを使われても、止められない場合がある。
  - 背景の元画像 `bg_*.png` には右下に Gemini の透かし（きらきらのマーク）が入っていた。ゲームでは 16:9 に切り抜く都合で画面に入らないが、透かしを消すことを目的にした加工はしないこと。目に見えない透かし（SynthID）は画像に残っている。
  - Steam で売る場合は、AI で作った素材を使っていることをストアの申請フォームで申告する（事前生成のコンテンツとして）。
  - 規約は変わることがあるので、販売の直前にもう一度読む。

## 素材を作りなおすとき

`tools/prepare_assets.py` が元の WinForms 版の `Resources` フォルダーから、透過・切り抜き・縮小・Ogg 化までを行います。

```bash
python3 tools/prepare_assets.py <元の Abbild フォルダー> --fonts <DotGothic16 のフォルダー>
```
