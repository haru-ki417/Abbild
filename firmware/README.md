# 自作コントローラー（Arduino）

`AbbildController/AbbildController.ino` を Arduino IDE で書き込みます。
ゲームを起動すると、つないだポートを自動で探します（「せってい」から固定もできます）。

## 部品

| 部品 | つなぐ先 | ゲームでの役目 |
| --- | --- | --- |
| 脈波センサー（PulseSensor 互換・アナログ） | A0 | 心拍（瞑想・凝視・交渉・バーサーク・キャラ作成の「心」） |
| 加速度センサー ADXL335（3.3V） | A1（X）・A2（Y）・A3（Z） | 振る・傾ける（気合ため・吊り橋・第六感・居合い など） |
| タクトスイッチ：決定 / もどる | D2 / D3（もう片方は GND） | 決定・連打 |
| タクトスイッチ：上 / 下 / 左 / 右 | D4 / D5 / D6 / D7（もう片方は GND） | メニュー・心眼でかわす |
| 温湿度センサー DHT11 | D8 | 息を吹きかける（凍結を溶かす・息吹） |
| RGB LED（カソードコモン）＋抵抗 220Ω×3 | D9（赤）・D10（緑）・D11（青） | ランプ（画面のランプと同じ色に光る） |
| 圧電ブザー | D12 | 効果音 |
| OLED SSD1306（任意） | I2C（A4・A5） | 演出（スケッチの `#define USE_OLED` を有効に） |

必要なライブラリ：DHT sensor library（Adafruit）。OLED を使うなら Adafruit SSD1306 と Adafruit GFX。

## 通信の形式

9600bps、1 行ずつ。

- コントローラー → ゲーム（20 回/秒）：`AB2,心拍,ボタン,加速度X(mg),Y(mg),Z(mg),方向,湿度,気温`
- ゲーム → コントローラー：`r` `g` `b` `y` `p` `w` `o` `m` `c`（LED の色）、`N` `S` `D` `F` `I` `T` `H` `P`（音）、`O:ENC` などの OLED の演出

WinForms 版のころの形式 `pulse,sw,x,y,z,temp,hum` も読めます（x は中心 330 の加速度、z は方向キー）。

## 天気（任意）

ESP などから `Rain,23,60`（天気,気温,湿度）か `W:Rain` を送ると、外の天気がゲームの天気になります（晴れ＝炎が強い、雨＝氷が強く炎が弱い）。
「せってい → 天気モジュール」でポートを選びます。

## 調整

- 心拍のしきい値は、キャラ作成の「心」の測定で安静時の値を覚えます。「せってい → 高ぶりの判定」で上がり幅を変えられます。
- 加速度の 0g と 1g の値は、スケッチの `ACC_ZERO` と `ACC_PER_G` で合わせます。「せってい → センサーの確認」で傾きと振りの数え方を見られます。
